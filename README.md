# Uzun Kısa Süreli Bellek Ağları (LSTM)

Bu klasör, LSTM ağlarına giriş ve uygulama notebook'larını; uygulamayla ilişkili zaman serisi verisini ve kaydedilmiş model dosyasını içerir.

## İçerik

- LSTM'e giriş
- LSTM uygulaması

## Veri ve model dosyaları

- `tsla_2025.csv`: TSLA hisse senedi verisi
- `best_model.keras`: kaydedilmiş Keras modeli

## Kullanım

Notebook'ları Jupyter Notebook veya JupyterLab ile açın. Veri ve model dosyalarını kullanırken notebook'ların göreli dosya yollarını koruyun; gereken kütüphaneleri notebook içindeki yönergelerden kontrol edin.
